# The demo

What GitHub Pages serves: one route map, paired with its elevation profile,
with nothing else on the page.

Deliberately minimal. `index.astro` calls `renderRouteMap` with a `route.json`
and lays the pieces out - no content collection, no image pipeline, no
framework beyond Astro itself - so what a visitor sees is the package rather
than a site built around it. `examples/astro/` is the fuller integration, with
a gallery behind the photograph dots.

```bash
npm install
npm run dev
```

The package is resolved from `../src` through Vite aliases, so a change to it
shows up here without a build step. A consumer installing from a tag resolves
the same specifiers through `dist/` instead, which is why the aliases spell out
every entry point rather than pointing at a directory.

## The data

`src/assets/` holds one ride's `map.jpg`, `route.json` and `elevation.svg`,
generated by [gpx-tools](https://github.com/TokyoDanInJapan/gpx-tools):

```bash
gpx-mapgen ride.gpx --outdir demo/src/assets --layer osm --post ride.md --overlay
```

The `osm` layer needs no API key, and `gpx-mapgen` stamps the attribution into
the image itself - which is why the tiles carry "© OpenStreetMap contributors"
along their bottom edge. Do not crop it off.

There is no `photos.json` here, because a demo has no photographs to show.
